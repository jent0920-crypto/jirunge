# 🪱 지렁이 대작전 (Jirunge) — 실시간 온라인 멀티플레이어

광고를 완전히 제거하고, 실시간 WebRTC P2P 기반 온라인 멀티플레이어 기능과 특수 아이템(바나나, 사과젤리, 두리안 방귀)을 추가한 고성능 HTML5 지렁이 게임입니다.

Vercel에 연동하여 바로 무료 호스팅할 수 있도록 정적 호스팅 및 P2P 네트워킹 아키텍처로 구현되었습니다.

---

## 🎮 주요 기능 및 특징

1. **🌐 실시간 온라인 멀티플레이어 (WebRTC P2P)**
   - 별도의 유료 소켓 백엔드 없이 PeerJS 및 STUN 서버를 활용한 초저지연(P2P) 실시간 대전.
   - **방 만들기**: 버튼 한 번으로 6자리 방 코드 생성 및 자동 초대 링크 복사.
   - **초대 링크 접속**: `https://<vercel-도메인>/?room=ABC123` 링크를 클릭하면 자동으로 같은 방에 즉시 입장.
   - **빠른 매칭**: 공유 공개 로비(`PUBLIC`)로 바로 접속하여 누구와도 즉석 대전.
   - **무한 리스폰**: 게임 도중 죽어도 바로 다시 태어나서 친구와 계속해서 승부 가능.

2. **⚡ 특수 아이템 시스템**
   - **🍌 바나나 (15초 주기)**: [F] 키 (모바일: 🍌 버튼). 주변 800px 내 상대 지렁이를 5초간 50% 감속.
   - **🍎 사과젤리 (30초 주기)**: [Space] 키 (모바일: 🍎 버튼). 1초간 점프하여 모든 충돌을 무시하는 완전 무적 상태 발동 (이동 및 부스트 가능).
   - **🍈 두리안 방귀 (30초 주기)**: [C] 키 (모바일: 🍈 버튼). 꼬리 뒤로 500px 방귀 구름을 뿜어 피격된 적을 0.5초 기절(회전 불가)시키고 10초간 몸집의 30%를 먹이로 배출시킴.

3. **🗺️ 스마트 미니맵 & 이모지 레이더**
   - 내 지렁이: `👍` 따봉 이모지
   - 상대 지렁이: `👎` 역따봉 이모지
   - 아이템 위치: `🍌` 바나나, `🍎` 사과젤리, `🍈` 가시 두리안 아이콘 실시간 표시.

4. **🚫 100% 무광고 & 최적화**
   - 모든 배너/전면 광고 제거.
   - 60 FPS requestAnimationFrame 렌더링 및 디바이스 픽셀비(DPR) 자동 튜닝.
   - 모바일 터치 및 가상 조이스틱 완벽 지원.

## 🚀 Vercel 배포 가이드 (30초 완성)

1. **[Vercel](https://vercel.com) 로그인**:
   - GitHub 계정으로 Vercel에 로그인합니다.
2. **새 프로젝트 추가 (Add New Project)**:
   - Dashboard에서 **"Add New..."** → **"Project"** 클릭.
   - 연동된 GitHub 리포지토리 목록에서 **`jirunge`** (또는 `ju96015140-png/jirunge`)를 찾아 **"Import"** 클릭.
3. **배포 (Deploy)**:
   - Build & Output Settings 등 모든 설정은 기본값(정적 웹사이트) 그대로 두고 **"Deploy"** 버튼 클릭!
4. **완료!**:
   - 배포가 완료되면 생성된 Vercel URL (예: `https://jirunge.vercel.app`)을 브라우저에서 열면 전 세계 누구와도 실시간 대전이 가능합니다!

## 💻 로컬 실행 방법

Node.js 환경에서 로컬 테스트를 진행할 수 있습니다.

```bash
# 1. 의존성 없이 로컬 서버 실행
npm start
# 또는
node server.js

# 2. 브라우저에서 접속
http://localhost:3000
```

## 🛠️ 조작법

- **이동**: 마우스 커서 방향 / 모바일 화면 터치 및 조이스틱 / 방향키 (`←`, `→`, `W`, `A`, `S`, `D`)
- **부스트 (⚡)**: 마우스 좌클릭 유지 / 스페이스바(Space) / 모바일 ⚡ 버튼 터치
- **바나나 슬로우**: `F` 키 / 모바일 `🍌` 버튼
- **사과 점프 (무적)**: `Space` 키 (사과젤리 보유 시) / 모바일 `🍎` 버튼
- **두리안 방귀**: `C` 키 / 모바일 `🍈` 버튼
- **일시정지**: `P` 또는 `Esc`
- **소리 끄기/켜기**: `M`
